# 🎮 Jokenpo Pro

Um jogo interativo de Pedra, Papel e Tesoura com interface moderna, animações e placar dinâmico.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## 🎯 Funcionalidades

- 🎮 Sistema de jogo completo (Pedra, Papel e Tesoura)
- 🤖 Escolha aleatória da máquina
- 🧠 Lógica otimizada para definição de vencedor
- 📊 Placar em tempo real (vitórias, derrotas e empates)
- 🎬 Animações durante as jogadas
- 🔄 Botão de reinício do jogo
- 🎨 Interface moderna com estilo neon
