## 🚀 Funcionalidades

- 🎮 Sistema de jogo completo (Pedra, Papel e Tesoura)
- 🤖 Escolha aleatória da máquina
- 🧠 Lógica de vitória otimizada com mapeamento de resultados
- 📊 Placar em tempo real (vitórias, derrotas e empates)
- 🎬 Animações de feedback durante as jogadas
- 🔄 Botão de reinício com reset completo do placar

---

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3 (estética arcade/neon, scanlines, efeitos de glow, animações com keyframes)
- JavaScript Vanilla (addEventListener, emoji maps, lógica de resultado, manipulação de DOM)
- Fonte [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) — identidade visual pixel/retro

---

## ▶️ Como Rodar Localmente

```bash
git clone https://github.com/Dvd-2405/Jokenpo.git
```

Abra o arquivo `index.html` no navegador. Sem dependências, sem instalação.

---

## 📚 O que eu aprendi

- Separação de responsabilidades com `addEventListener` (sem handlers inline no HTML)
- Uso de objetos como mapas de dados (emoji maps e tabela de resultados)
- Manipulação de DOM para atualização de placar e feedback visual
- Criação de interfaces com identidade visual consistente usando CSS puro
- Experiência do usuário: feedback imediato a cada jogada
